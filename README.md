# Undertale Skeletonu apgerbsana
## Apraksts
Uz Undertale balstīta skeletu apgerbsana, ļauj lietotājam saģērbt Sans un Papyrus. Spēlē ir liela apģērbu izvēle.
## Funkcionalitate
- [X] - Fonu mūzika
   - Fona mūzika ir pieejam gan spēlē, gan pirmsekrānā.
- [X] - Skaņu efekti
  - [X] - Uzspiežot uz tēla tas runā
- [X] - Vecuma aprēķins
  - [X] - Iespēja ievadīt tēla vārdu
  - [X] - Iespēja ievadīt dzimšanas gadu (Min-1926, Max-2026)
- [X] - Tēlu apģērbšana
   - [X] - Nav tieši drag un drop princips, bet ir click un drop.
   - [X] - Iespejams tikai viens no apģērbu gabaliem.
   - [X] - Četri apģērba veidi, katram trīs opcijas.
- [X] - Scroll view apraksts, unikāls tēlam.
- [X] - Slideri kas maina tēla platumu un augstumu respektīvi.
